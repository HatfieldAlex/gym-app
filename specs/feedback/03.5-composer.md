# 03.5 — The composer

**Goal:** type the thought, send it, panel closes, back to what you were doing.
The chunk that makes the feature real.

Needs chunk 02 (the endpoint) and chunk 03.0 (the panel to put this in).
Frontend only.

## Read first

- `FeedbackMarker.jsx` as chunk 03.0 left it
- [Settings.jsx](../../frontend-web/src/pages/Settings.jsx) — the project's
  pattern for a write: local `busy` / `failed` state, a disabled button while in
  flight, an error line afterwards. Copy it; do not reach for `useLoad`, which
  is for reads.
- [api.js](../../frontend-web/src/api.js) — `api.post`, and `ApiError.detail`

## Build

1. **The form**, replacing chunk 03.0's placeholder line inside the panel:

   - a `<textarea>`, three or four rows, with a real `<label>` (visually hidden
     if the heading already says it) and a placeholder like "What happened, or
     what would be better?",
   - a **Send** button using the existing `.button` class,
   - chunk 03.0's **Close** button, unchanged.

   Autofocus the textarea when the panel opens — chunk 03.0 already moves focus
   into the panel; this is where it lands. The thought is why the panel was
   opened, so typing should be possible without a second tap.

2. **Sending.** `api.post('feedback-notes/', { body })`. `body` is the textarea
   trimmed. Send is disabled while the trimmed text is empty and while a request
   is in flight (no double-send), and reads "Sending…" while it is (A9's spirit:
   no optimistic UI, no rollback machinery — the button waits).

3. **The three outcomes**, and what each leaves behind:

   | Outcome | The panel | The draft |
   |---------|-----------|-----------|
   | Sent | Shows "Logged." in place of the form, then closes itself after about a second and a half. | Cleared. |
   | Failed | Stays open, with one `.status[data-state="error"]` line — "Could not log that. Try again." — above the buttons. | **Kept, exactly as typed.** |
   | Still sending | Stays open, Send disabled and labelled "Sending…". | Untouched; the textarea stays editable. |

   On the success beat: the four dismissals from chunk 03.0 still work, so
   Escape or a tap outside closes it immediately rather than waiting out the
   timer. Clear the timer if the panel is closed or unmounted first — a
   `setState` after unmount is a bug, not a warning to live with.

4. **The draft outlives the panel (B6).** Hold the textarea's value in
   `FeedbackMarker`, next to the open/closed state — not inside the panel, which
   unmounts on close. Closing the panel with text in it and reopening it, from
   the same page or another one, comes back to the same half-written sentence.
   It is cleared on a successful send and at no other time.

5. **Ctrl/Cmd + Enter sends** from inside the textarea, so a note can be
   finished without reaching for the button. A bare Enter inserts a newline, as
   a textarea should. Escape still closes (chunk 03.0), draft intact.

6. **Failures say what happened, once.** Use `ApiError.detail` when the API
   returned a message (a 400 from the serializer's own validation), and the
   generic line otherwise. A 401/403 — the session expired mid-workout — reads
   "Your session has expired. Please log in again.", matching
   [Status.jsx](../../frontend-web/src/components/Status.jsx). Clear the error
   the moment the user types again, so a retry does not argue with a stale
   message.

7. Style the additions in the `/* Feedback marker and panel */` section chunk
   03.0 opened. Plain is fine; chunk 06 does the ergonomics.

## Done when

- Open the panel on **Current session** mid-workout, type a sentence, tap Send:
  "Logged." appears, the panel closes on its own, and the session on the page
  behind is exactly as it was — same exercise held, same sets listed, nothing
  re-fetched, nothing lost.
- The note is in the admin (chunk 01) with that body, `kind` *idea*, and the
  right owner.
- Ctrl+Enter (Cmd+Enter on a Mac) from the textarea does the same as Send.
- Send is disabled on an empty box and on whitespace alone, and cannot be
  double-tapped into two notes.
- With the backend stopped, Send shows the error line and the typed text is
  still there; starting the backend and tapping Send again logs exactly one
  note.
- Type half a sentence, press Escape, navigate to another page, reopen: the half
  sentence is still there. Send it, reopen: the box is empty.
- Closing the panel during the "Logged." beat does not throw, and no warning
  about updating an unmounted component appears in the console.
- The whole round trip — marker, type, send, gone — is possible with the
  keyboard alone and without the page underneath scrolling or reloading.

## Do not

- Confirm with an alert, a toast library, a snackbar, or a browser
  notification. The panel says "Logged." and leaves.
- Keep the panel open after a successful send, or reopen it afterwards.
- Send a partial note on close, on blur, or on a timer. Send is a tap.
- Store the draft in `localStorage`, `sessionStorage` or a cookie (B5) — React
  state above `<Routes>` already survives everything except a reload.
- Re-fetch, refresh or invalidate anything on the page underneath after sending.
- Add `kind` or `page_path` to the request — that is chunk 04, and the serializer
  defaults them.
- Add a character counter, a preview, drafts list, or an undo.

## What the user sees

**The panel becomes usable, and the loop closes.** Mid-set, a thought arrives:
tap 💡, type it, Send, and it is gone from your head and into the app — three
seconds, no page left, no place lost.

- **The cursor is already in the box** when the panel opens. No second tap
  before typing.
- **Send is dim until there is something to send**, so an empty tap cannot file
  an empty note.
- **Sending says "Sending…", then "Logged.", then the panel leaves by itself.**
  No dialog to dismiss, no confirmation to acknowledge, and the screen behind is
  untouched — same scroll, same workout, same everything.
- **Ctrl+Enter sends**, for anyone typing on a keyboard.
- **A failure keeps the words.** If the request does not land, the panel stays
  open, says so plainly, and the sentence is still in the box to send again.
- **A half-written thought is never lost.** Close the panel, walk to the next
  machine, change page, open it again — the sentence is waiting. It disappears
  only once it has actually been logged.

What it cannot do yet: say whether the note was an idea or a bug, or record
which screen it was written on. Chunk 04 adds both without adding a step.
